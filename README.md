# 🏦 Loan Approval Analysis

## 📌 About Project
This project analyzes loan applications to identify factors affecting loan approval and rejection.

## 🎯 Objective
- Analyze loan approval and rejection
- Identify risk factors
- Analyze applicant financial information
- Find useful business insights

## 🛠️ Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Analysis
The project includes:
- Data Cleaning
- Exploratory Data Analysis
- Loan Approval Analysis
- Risk Analysis
- Applicant Segmentation
- Data Visualization

## 🔍 Key Factors
- Credit Score
- Annual Income
- Loan Amount
- Previous Default
- Debt-to-Income Ratio
- Risk Level
- Employment Stability
- Existing Loans

## 🏁 Conclusion
This project demonstrates how Python-based data analysis can be used to understand loan approval patterns and identify important risk factors.
